Download the latest release for your platform from https://github.com/FRC2207/RoboRoute/releases/latest

Extract the files from the archive, and run the NTOverAOA application

### Installing the Android App
Select the usb device in the connection tab
Navigate to the setup tab, and browse for an APK, select the one from the extracted directory and click install, there will be a prompt on the device that you will need to accept

### Driver Setup (Windows Only)
Navigate to the setup tab, select the usb device, and click install driver
:::danger[Selecting the wrong usb device can result in a system driver being replaced, or another usb device becomming unuseable]
